# Windows Executable-Extension Test Samples (Benign)

A set of **benign placeholder samples** for **DLP file-classification / file-extension recognition research**.

## Purpose
- Test how DLP systems identify, classify and enforce policies on Windows executable/script extensions
- Validate file-type detection (extension, magic number, content)
- Authorized security research and product verification

## Important
- **No real executable code, PE header (MZ), script logic or malicious payload.**
- Each sample contains only one line of plain text, e.g.: `Benign DLP test sample (.exe). No executable code. ...`
- All files are benign placeholders for authorized security research; not malware.
